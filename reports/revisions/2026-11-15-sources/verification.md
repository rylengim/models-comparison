# Проверка итерации источников

Ветка `codex/hw1-sources-errors`, исходная точка `d43cffe` после P0.
Проверка выполнена локально, без внешней сети, ключей, новых списаний и публикации.

## Тесты

- Основная среда Python 3.14: **690 passed, 3 skipped**. Пропущены три модуля Milvus,
  отсутствующего в основной среде; 13 предупреждений стороннего плагина LangSmith
  об устаревающем API Python не связаны с изменениями.
- Эти три модуля отдельно в установленной среде ДЗ 2/Python 3.12:
  **10 passed**. Использованы временные локальные базы, подставные эмбеддинги
  и вымышленные сообщения.
- Новые регрессии подтверждены RED→GREEN: потеря HTTP-кода и этапа ошибки,
  malformed-ответ вместо пустой выдачи, потеря диагностики при усечении,
  фильтрация официальных ссылок после преждевременного лимита,
  некорректные/длинные адреса, неизвестный формат наблюдения и противоречивая диагностика.
- Проверены весь цикл «поиск → найденный URL → защищённое чтение → финальный ответ»
  и сохранение резерва последнего ответа без инструментов. Ответы модели
  и HTTP полностью подставные, не включены в измеренные результаты.
- Проверены прежние пять режимов, семь `--bonuses`, новые явно выбранные настройки,
  чтение старого манифеста отчёта и запрет resume при изменении зависимостей
  нового поиска/диагностики. Фикстуры ДЗ 3 дополнены новыми файлами протокола.
- Независимое ревью подтвердило исправление найденных границ URL, схем,
  усечения вывода и классификации аудита. Оставшихся блокеров не обнаружено.

При проверках ключи удалены из окружения, загрузка `.env` отключена; соединения
и внешний DNS запрещены защитным запуском. Импорт Milvus вызывает `load_dotenv`:
в тестовой среде он заменён пустой функцией, не открывающей файлов. Разрешённый
разбор числовых IP не обращается к DNS.

## Исполнение без модели

Реально выполнены CLI `schemas --official-sources` и `freshqa.source_audit` с
запрещёнными чтением credentials и сетью. Схема содержит `official_search`,
а аудит обрабатывает 725 замороженных ответов и 100 подробных результатов
собственных вопросов. В нём сохраняются 727 хешей входов и хеши проверяющего кода.

Все **1109 защищённых исходных артефактов**, включая ревизию P0, сохранили
контрольные суммы до/после работы. Эталоны, ответы, расходы и старые отчёты
не переписывались. Новые результаты находятся только в этом каталоге.

Прирост точности, текущая доступность поисковика/сайтов, реальные цена и задержка
нового режима не измерялись. Проверки не доказывают улучшение прежних 2/20.
