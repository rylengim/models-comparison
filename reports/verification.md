# Проверка реализации

Дата: 2026-10-29. Среда: Linux, Python 3.14.4. Платных LLM-вызовов не было.

- **118 тестов проходят**: инструменты, цикл, клиент, стоимость, метрика, продолжение
  эксперимента, отказ при прерывании/неизвестной цене и итоговая отчётность.
  Вывод сохранён в [tests.txt](tests.txt).
- Полный интеграционный тест запускает настоящий цикл и калькулятор через
  подставной HTTP-ответ в временной папке; проверяет пять строк, стоимость и resume.
  Его синтетические данные не попадают в `traces/` или результаты эксперимента.
- Проверка формата всех записей запускается без ключа: [format_check.txt](format_check.txt).
- Живые HTTP-запросы: Wikipedia search возвращает выдачу, full-text article retrieval
  и чтение официальной страницы ESA/Hubble работают. DuckDuckGo возвращает антибот-проверку;
  это явно отражается ошибкой инструмента. Подробности без копирования длинных текстов:
  [availability.json](availability.json).
- В публичном каталоге OpenRouter найдены все три выбранных model ID; tool calling
  указан как поддерживаемый. Это не заменяет проверку реального вызова с ключом.
- Проверены CLI `--help`, `schemas`, `validate`, `report`, а также понятный отказ
  `check_fresh.py --sonnet` без ключа. Проверен внешний вид графика состояния без замеров.

Код прошёл независимый просмотр по корректности, расходам и безопасности. Исправлены:
сброс уже учтённых расходов при resume, потеря учёта после прерывания, ошибочная отметка
завершённого эксперимента при API-сбоях, обработка испорченного URL, сравнение дат и чисел.

**Ещё не проверено:** реальные ответы моделей, пригодность промптов для полного набора,
критерий свежести ≤20%, итоговые расходы/точность и два реальных провала. Никаких выводов
об улучшении качества агента по этим локальным тестам не делается.
