# Проверка реализации и результатов

Дата: 2026-10-30. Linux, Python 3.14.4.

## Код и установка

В новом чистом локальном клоне коммита `ba0a55e` создан отдельный venv,
зависимости установлены из `requirements.txt`. `pip check` не нашёл конфликтов,
**170 тестов прошли**. Валидация 145 записей, схемы и генерация отчёта работают
без ключей. `.env` не переносился; переменные ключей удалены из окружения,
`PYTHON_DOTENV_DISABLED=1`. [Полный лог](run_metadata/clean-clone-final.log),
[вывод тестов](tests.txt).

Тесты используют подставные ответы и не обращаются к моделям или сети.
Проверяются инструменты, основной цикл, учёт расходов, сохранение прерываний,
resume, оценка и отчёт. Дополнительные 19 тестов покрывают общую очередь,
глобальную остановку и постоянную HTTPS Session без автоматических повторов.
Основной пакет заморожен до полного эксперимента; поздние изменения затронули
только внешнюю обёртку `reports/run_paced.py`, её тесты и документацию.

## Реальный эксперимент

[Аудит всех трейсов](run_metadata/final_trace_audit.json) подтвердил:
725 записей, 145 уникальных ID в каждом из пяти режимов, одинаковые манифесты,
неизменные хеши пакета и датасета, соответствие модели/вопроса/эталона,
совпадение сохранённых оценок с фиксированной метрикой. Все 2107 request ID
завершённых попыток уникальны; суммы `usage.cost` равны суммам трейсов,
число шагов совпадает с событиями и не превышает шести.

Нет `inflight`, неизвестных расходов или API-ошибок в итоговых каталогах.
`max_steps` и `repeated_tool_call` — завершение агента по ограничителю, а не
неразобранный API-сбой; правильность таких ответов оценивается отдельно.
Sonnet: все 145 статусов `ok`, 1 зачтённый ответ, критерий ≤20% выполнен.

Два чтения API key/credits после остановки всех генераций подтвердили
**$1.75129015**: основные завершённые попытки, пилоты и архивированные
прерывания. Первые чтения после окончания ещё не включали все последние
списания; объединение выполнено после сходимости. [Сверка](expenditure.json).
Каталоги двух отдельных процессов скопированы без перезаписи существующих
трейсов, после проверки одинаковых манифестов.

График просмотрен, обе трактовки расходов опубликованы. Два разбора ошибок,
парные сравнения и ограничения проверены независимо по полным JSON.
[Результаты](report.md), [интерпретация](analysis.md), [провалы](failures.md).

## Воспроизведение полного отчёта

Финальная проверка сохранённых 725 трейсов в чистом клоне выполняется отдельно
от установки; её результат будет добавлен после фиксации артефактов в Git.

## Диагностики вне основного сравнения

OpenRouter-пилоты: 12 ответов, 29 вызовов, $0.04370935; учтены отдельно.
Groq: три профиля на одном вопросе, оценка $0.0008115, реальное списание неизвестно.
Wikipedia и чтение страницы ранее проверены живыми HTTP-запросами; DuckDuckGo
вернул антибот-проверку, бонус за него не заявляется. Бонусный каскад и часть 2
не измерялись. Низкий Sonnet baseline отражает выбранную выборку и промпт,
а не универсальную оценку модели. Статистическая значимость не заявляется.
