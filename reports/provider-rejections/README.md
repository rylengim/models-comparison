# Отклонённые запросы и продолжение

2026-10-30 первый запрос `strong_no_tools/fresh-30` отклонён HTTP 429 до генерации.
Автоматического повтора не было. API `key` и `credits` показали суммарное списание
$0.08273335, точно равное $0.04370935 за пилоты и $0.039024 за первые 30 вопросов.
Неучтённого списания нет. Исходный трейс отказа сохранён здесь; после паузы
выполнено ручное продолжение `--resume` на неизменных коде, данных и настройках.
Успешные ответы не повторяются. Отказ не считается содержательным ответом модели.

[Документация OpenRouter об ошибках](https://openrouter.ai/docs/api/reference/errors-and-debugging)
описывает HTTP 429 как ограничение частоты и допускает `Retry-After`.
При первом отказе клиент сохранил статус, но не заголовок; его длительность неизвестна.

Второй HTTP 429 отклонил первый запрос `fresh-50`. Сверка API: $0.10403935,
совпадает с леджером, отказ не тарифицирован. С этого вопроса применён
`reports/run_paced.py`: минимум 3.5 секунды между стартами запросов, без повторов.
Промпты, инструменты и параметры генерации неизменны. Время ответа с этого места
включает ожидание ограничителя; сравнение секунд не является чистым тестом скорости моделей.

Режим `cheap_search/fresh-21`: третья отправка завершилась сетевым сбоем.
Две последующие сверки key/credits дали $0.23284555 — точно сумму всех известных
списаний. Неподтверждённого списания не осталось. Прерванная попытка сохранена:
два успешных вызова стоили $0.00023955, сбойная отправка — $0 по сверке баланса.
Эта попытка не является завершённым замером вопроса. Её расходы учитываются
отдельно в общих расходах проекта, как и пилоты; сравнительная таблица использует
завершённые попытки итогового прогона. После сверки вопрос можно запустить заново.

Во время параллельной фазы сетевой сбой на `cheap_search_read/fresh-8`
остановил очередь. Уже начатые `cheap_search/fresh-29` и
`medium_search_read/fresh-12` завершились локальным отказом перед следующим POST.
Все три попытки сохранены здесь. Две сверки показали $0.34991610 — сумму
всех известных вызовов; сетевой запрос не добавил списания. Расходы трёх
прерванных попыток: $0.00726585; вместе с первой — $0.00750540.
После сверки снята блокировка общей очереди и повторены только эти три
незавершённых вопроса. Манифесты, payload, данные и код не менялись.
Подробности: [сверка 2](billing_reconciliation_2.json).

Следующий сетевой обрыв на `cheap_search_read/fresh-10` аналогично остановил
незавершённые `cheap_search/fresh-32` и `medium_search_read/fresh-15`. Две сверки:
