## Ограничения эксперимента

В исходнике сохранены 72 значения `agent_ok=true` и 53 значения `agent_ok=false`; 107 сохранённых `sonnet_answer` равны `unknown`. Это исторические поля предоставленного файла. Они не являются результатом запуска реализуемых в этом проекте агентов и не должны включаться в сравнительную таблицу новых экспериментов.

Нормализованное сравнение с сохранёнными `sonnet_answer` даёт 0 совпадений из 125, но предоставленный `fetch_fresh.py` специально отбрасывает вопросы, на которые сильная модель ответила правильно. Поэтому это характеристика уже отобранной старой выборки, а не новый независимый тест свежести. Метка `agent_ok` относится к отдельному агенту с поиском и не противоречит ответу `unknown` у модели без инструментов.

Новых обращений к LLM API при подготовке датасета не было. Критерий «сильная модель без инструментов отвечает правильно не более чем на 20%» для объединённого набора **ещё не измерен**. Перед окончательной сдачей нужен реальный отдельный прогон с указанием модели, даты и полных результатов; при превышении порога вопросы следует заменить и повторить проверку.

Новые вопросы сосредоточены на астрономии и идут парами по статьям. Такой набор полезен для воспроизводимого поиска по официальным источникам, но не представляет все предметные области; вопросы внутри пары статистически зависимы. Существование свежей публикации само по себе не гарантирует, что модель без поиска не знает ответ.
