# ДЗ 1: источники и диагностика, итерация 2

Работа выполняется локально. Запросы к источникам и моделям, установка пакетов и публикация не входят в эту итерацию. Исходные измерения и ревизия P0 сохраняются.

## Контракт

- Новый режим `cheap_official_sources` включается явно. Пять обязательных режимов и прежний набор `--bonuses` сохраняются.
- `official_search` принимает текст запроса и необязательную группу источников. Каталог содержит только пять доменов: Hubble, Webb, ESO, ALMA, Chandra. Эталоны, evidence, ID вопросов и правильные URL не передаются поиску.
- Один вызов поиска делает не более одного запроса DDG HTML. Результаты фильтруются по официальным host до ограничения пяти ссылок. Это не обещание доступности внешнего поисковика.
- Найденная ссылка читается существующим `page_find` с проверкой публичного адреса, закреплением DNS/TLS, запретом редиректов и ограничением размера. Сниппет не подменяет чтение первоисточника.
- Каждое новое наблюдение источника имеет `diagnostic`: версию, этап, исход, тип ошибки, известный HTTP-код и признак допустимости повтора. Ошибки не сохраняют произвольный текст исключения, заголовки или ключи.
- Автоматических повторов нет. Лимиты вызовов модели и резерв последнего ответа действуют как прежде.
- Старые `HTTPError` сохраняются как ошибки с неизвестным HTTP-кодом. Не восстанавливаем причину по более поздней диагностике.
- Техническое наблюдение, финальный ответ и правильность факта — независимые поля. Наличие сетевой ошибки не считается доказанной причиной неправильного ответа.

## Состояния

Источник: проверка аргументов → поиск/проверка URL и DNS → загрузка → разбор и извлечение → результат, пустая выдача или структурированная ошибка. Ошибка завершает вызов без скрытого повтора.

Агент: вызов модели → валидация/проверка повторов инструментов → наблюдение → следующий вызов; существующие лимиты переводят в последний ответ без инструментов. Новый поиск не получает отдельного неограниченного цикла.

Аудит: проверка манифеста, набора и покрытия → чтение замороженных наблюдений → независимая оценка признаков → отдельный новый отчёт → проверка неизменности входов. Новые выводы не переписывают принятые результаты.

## Приёмка

1. Регрессионные тесты показывают официальный поиск, фильтрацию доменов и передачу найденного URL в защищённое чтение; отрицательные тесты не допускают поддельные host и приватные адреса.
2. HTTP 403/429/503, таймаут, DNS, редирект, ограничение загрузки, неверный формат и пустая выдача различимы; отсутствие сведений остаётся явным.
3. Аудит воспроизводит 40 HTTPError в 12 собственных трейсах Mini с чтением и показывает нулевое число явных первичных URL. Правильные ответы с ошибками не теряются.
4. Старые манифесты читаются для отчётов; новый протокол не возобновляет старое измерение. Все зависимости нового инструмента включены в хеши протокола.
5. Локальные тесты проходят, исходные артефакты сохраняют контрольные суммы. Новый показатель точности на реальной модели не заявляется.
