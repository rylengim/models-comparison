# ДЗ 3: эксперимент до 12 ноября 2026, 23:59 МСК

Продолжаем агента HW1 с теми же четырьмя инструментами, промптом и моделью.
Берём первые 40 записей собственного `data/fresh.jsonl`, чьи URL есть в фиксированном корпусе. Выбор зависит только от наличия источника.
Фреймворк: явный StateGraph LangGraph; паттерны: критик с опорой и план.
Эталон доступен только оценщику. Все LLM проходят через один httpx.Client.

1. Счётчик и лимиты: HTTP-журнал с конфигурацией/вопросом, реальные usage.cost,
   запрет продолжения при неизвестном списании. Проверка тестами fake transport.
2. Цикл и граф: одинаковое тело первого запроса и схемы инструментов, явные
   переходы MODEL / TOOLS / ANSWER / LIMIT / ERROR. Проверка тестами.
3. Критик: initial → check → accept либо revise (не более двух). План:
   отдельный вызов → тот же исполнитель. Общий потолок вызовов на весь вопрос.
4. Пилот, затем пять конфигураций на 40 вопросах. Бюджет новых вызовов ≤ $2.
   Последовательный журнал и сохранение каждого ответа; свежие результаты
   не смешиваются с историческими выводами предоставленного ноутбука.
5. Отчёт: таблица/график, побайтовая проверка пустого запроса, демонстрация
   лимита, ручная проверка до 10 неверных ответов каждой конфигурации.
6. Полная проверка существующих и новых тестов, README и учебный конспект.

Формат сдачи: публикация в GitHub, ветка `codex/hw3-patterns`, ссылка на папку `hw3`.

Завершено 12 ноября: 200 ответов, проверка 68 ответов, один исправленный эталон, 719 модельных HTTP-вызовов с общим расходом $0.20497860. Протокол адаптирован после HTTP 429 живой Википедии; диагностика сохранена отдельно.
