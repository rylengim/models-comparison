# Завершение ДЗ 1 по AI-агентам

Обновлено 2026-10-30. Обязательный эксперимент завершён: пять режимов на
145 вопросах, 725 ответов и 2107 LLM-вызовов в завершённых попытках.
Требования: [docs/PLAN.md](../docs/PLAN.md).

## Результат

- Все 125 исходных вопросов сверены с источниками; 40 содержательно уточнены.
  Добавлены 20 астрономических вопросов по 10 официальным публикациям.
- Sonnet 4.6 без инструментов: 1/145, критерий ≤20% пройден.
- GPT-4o mini: без инструментов 0/145, поиск 57/145, поиск и чтение 70/145.
- Haiku 4.5 с поиском и чтением: 71/145; лишь один дополнительный зачёт
  при стоимости задачи в 12,67 раза выше, чем у дешёвого режима с чтением.
- 170 тестов прошли в новом чистом клоне. Основной пакет и данные во время
  измерения не менялись; все манифесты и 725 записей проверены.
- Общий расход OpenRouter $1.75129015: основные попытки $1.68875360,
  пилоты $0.04370935, восстановление $0.01882720. Две сверки с API совпали.
- Сохранены таблица, график, два разбора ошибок и памятка для защиты.

## Принятые решения

OpenRouter — выбранная реализация, а не требование задания. Для свежести нужна
именно Sonnet 4.6. Расходы берутся из `usage.cost`; тарифная оценка Groq
остаётся отдельной диагностикой и не смешивается с ними.

Эталоны и цитаты не передаются модели. Метрика зафиксирована до эксперимента;
ложные положительные/отрицательные случаи разобраны, но баллы не подгонялись.
Код и данные заморожены; менялись только транспортная обёртка и расписание.
Различия расписания и доступности HTTP ограничивают сравнение времени и причин
ошибок. При сетевых сбоях и HTTP 429 прерванные попытки архивировались,
учёт сверялся, продолжались только незавершённые вопросы.

Рабочий общий бюджет — $5. Лимит проверяется между запросами; последний вызов
может пересечь порог. Реальные расходы и архивы подтверждают итоговую сумму.
Бонусы и необязательная личная задача из части 2 в основной результат не входят.
