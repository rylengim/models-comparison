## 3. Проверить OpenRouter на небольшом пилоте — S

OpenRouter указан как текущий реализованный путь, а не требование преподавателя.
Сначала проверить доступные пробные кредиты; при выборе прямого Claude API
добавить отдельную задачу адаптации клиента и учёта до запуска пилота.

- [ ] Локальный доступ к выбранным моделям работает; Sonnet — именно версия 4.6.
- [ ] Пилот в отдельном каталоге даёт читаемые ответы, рабочие вызовы инструментов
  и подтверждённый `usage.cost` без передачи эталонов модели.
- [ ] До основного запуска устранены обнаруженные ошибки и зафиксированы код/настройки.

Проверка: вручную прочитать пилотные JSON-трейсы и учёт расходов.
Зависимости: 1, ключ OpenRouter; репрезентативные вопросы из 2.
Файлы: локальный `.env` (не Git), отдельные пилотные каталоги в `tmp/`.
