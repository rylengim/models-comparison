# Трейсы итогового прогона

Пока отсутствуют: у пользователя нет API-ключа (2026-10-29).
Никакие тестовые ответы не выданы за реальные прогоны.

`python -m freshqa benchmark` создаёт `manifest.json` и
`<конфигурация>/<id-вопроса>.json`. Каждый трейс включает вопрос, итоговый ответ,
действия и наблюдения, токены, стоимость и время, а также эталон и результат оценки,
добавленные **после** ответа агента. Модель видит только question.

`--resume` пропускает сохранённые вопросы и восстанавливает известные расходы.
Смена кода, моделей, набора или max_steps требует нового каталога.
Трейсы с неопределённым списанием автоматически продолжать нельзя.
